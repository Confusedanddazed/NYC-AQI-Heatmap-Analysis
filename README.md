# NYC AQI Heatmap Analysis 🌫️🗽

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/1jcFtYCiT66_URrYaxAjy420iWQnsP_gY)

This project visualizes how the 2023 Canadian wildfires impacted air quality across New York State. Using EPA AQI and PM2.5 data, it creates interactive choropleth maps and time-series plots to compare air quality during the wildfire season (May–July) against the baseline period (Jan–April).

## 🧰 Technologies Used
- Python (Google Colab)
- Pandas
- Plotly Express
- GeoJSON
- EPA AQI Dataset

## 📁 Data Source
[EPA Air Quality System (AQS)](https://www.epa.gov/aqs)

## 📊 Key Features
- Choropleth maps of AQI by county (May–July vs Jan–April)
- Time-series analysis of PM2.5 and NO₂
- Correlation plots between PM2.5, NO₂, and AQI
- Uses GeoJSON for mapping NY county-level data
